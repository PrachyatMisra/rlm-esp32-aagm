# Hardware-Free Verification Suite

This project includes a complete, self-contained verification suite that allows full validation of the firmware engine, numerical parity, digital control policy, and serial communication without requiring a physical ESP32 development board.

## Verification Tiers

1. **Host-Native C++ Parity Harness (`firmware/test/host_harness.cpp`)**:
   - Compiles the actual shipping C++ engine (`firmware/rlm_esp32/src/rlm_engine.cpp`) and zero-vocabulary tokenizer (`tokenizer.cpp`) natively with `g++`.
   - Runs against 12 golden test vectors generated by the PyTorch int8 mirror (`tools/out/golden_vectors.txt`).
   - Asserts exact matching of token IDs, step counts, predictions, and numerical tolerances:
     * $|logit\;error| < 2.0 \times 10^{-2}$ (measured: $2.86 \times 10^{-6}$)
     * $|gate\;error| < 1.0 \times 10^{-3}$ (measured: $5.36 \times 10^{-7}$)
     * $|depth\;error| < 5.0 \times 10^{-3}$ (measured: $5.36 \times 10^{-7}$)

2. **Digital RTL Control Policy Verification (`verification/verilog/`)**:
   - Validates the digital control logic around the neural engine (`aagm_gate.v`):
     * Minimum step enforcement ($k \ge K_{\min} = 2$)
     * Cumulative halting mass threshold in unsigned Q1.15 fixed-point arithmetic ($\ge 29491 \equiv 0.900$)
     * Energy budget exhaustion override
     * Asynchronous mid-inference abort signaling
   - If Icarus Verilog (`iverilog` & `vvp`) is installed, it compiles and runs the Verilog testbench.
   - If Icarus Verilog is not installed, the `Makefile` automatically runs the built-in cycle-accurate reference simulator (`sim_aagm_gate.py`), verifying all 6 vectors and generating an IEEE 1364 standard VCD waveform file (`aagm_gate.vcd`).

3. **Mock FreeRTOS UART Client (`host/gateway.py --mock`)**:
   - Communicates with `host_harness --interactive` over standard I/O, reproducing the exact FreeRTOS serial protocol.
   - Tests `STAT`, `PING`, `MODE` sweeps (PERF/BAL/ECO), `BATT` voltage adjustment, and inference benchmarking.

## Commands

Run all checks from the repository root:

```bash
# 1. Verify firmware C++ numerical parity
make -C firmware/test check

# 2. Verify digital Verilog control policy & generate VCD waveform
make -C verification/verilog check

# 3. Run self-test and generate verification artifacts
python3 host/gateway.py --selftest

# 4. Run labeled evaluation set through mock serial bridge
python3 host/gateway.py --mock --eval
```

All verification artifacts are saved to `artifacts/`:
- `esp32_parity.json`: Full numerical parity report
- `esp32_eval_telemetry.json`: Device inference records
- `esp32_gating_analysis.svg`: 4-panel mechanism dashboard
- `esp32_energy_model.svg`: Energy index and current draw per profile
